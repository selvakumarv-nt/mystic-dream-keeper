🌙 Dream Journal

Capture your dreams before they fade away.

A calm, modern dream journal with a moon-and-stars theme. Write your dreams down, keep them safe, and rediscover the patterns inside.

🌐 Live App: https://dreamcatcher-night-notes.lovable.app/

✨ Features
🌌 Calm interface – a dark, glass-style design that feels like nighttime
✍️ Easy entries – add a title, date, and description in under a minute
🔒 Private by design – dreams are stored in your own browser, with no account needed
📖 My Dreams page – view and revisit all your saved dreams in one place
📱 Responsive layout – works on phones, tablets, and computers
📄 Pages
Page	Purpose
Home	Introduction and quick start
My Dreams	Write new dreams and read saved ones
About	Why keeping a dream journal helps
Contact	Get in touch
💡 Why Keep a Dream Journal?
Better recall – writing dreams strengthens your memory of them
Creative spark – many artists and scientists keep dream notes for ideas
Emotional clarity – patterns in your dreams can show what's on your mind
Lucid awareness – regular journaling is a first step toward lucid dreaming
🛠️ Built With
Lovable – used to build and host the app
Browser storage – saves your dreams privately on your device
▶️ Run It Locally
Clone the repository
bash
   git clone https://github.com/selvakumarv-nt/mystic-dream-keeper.git
Go into the folder
bash
   cd mystic-dream-keeper
Install dependencies
bash
   npm install
Start the development server
bash
   npm run dev
Open the link shown in your terminal (usually http://localhost:5173).

You need Node.js installed on your computer.

🔐 Privacy

Your dreams never leave your browser. There are no accounts and no tracking. Clearing your browser data will remove your saved dreams.
